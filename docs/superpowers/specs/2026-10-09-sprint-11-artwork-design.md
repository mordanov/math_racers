## Problem Statement

All game artwork assets are present in `assets/artwork/` (Vite `publicDir` is `../assets` so files serve at `/artwork/<name>`). Two pages reference artwork at wrong root-level paths. Three pages have no artwork at all. Individual achievement badge icons in `assets/achievements/` are already referenced correctly via `getBadgeUrl()`.

## Section 1: Path Fixes

**`HomePage.tsx`**: change `backgroundImage: 'url(/mainmenu.png)'` → `url(/artwork/mainmenu.png)`.

**`RaceScreenPage.tsx`**: change `backgroundImage: 'url(/stadium.png)'` → `url(/artwork/stadium.png)`.

Two one-line edits. No new tests needed — visual regressions caught by existing test suite (tests don't assert on `backgroundImage`).

## Section 2: Avatar Generation Illustration

**`AvatarCreatorPage.tsx`**: The page shows a waiting state while the avatar portrait is being generated by the AI backend. Add `avatar_generation.jpeg` as a centred illustration image in this waiting state.

Placement: between the loading spinner (or heading) and the status text. Use a fixed display size (e.g. `width: 240px`, `borderRadius: tokens.radius.lg`, `objectFit: 'cover'`) so it does not affect layout on different screen sizes.

```jsx
<img
  src="/artwork/avatar_generation.jpeg"
  alt=""
  aria-hidden="true"
  style={{ width: 240, borderRadius: tokens.radius.lg, objectFit: 'cover' }}
/>
```

`alt=""` / `aria-hidden="true"` — decorative image, no alt text needed.
