## Version Roadmap

```
v1.0  Initial release
  ↓
v1.5  Content expansion
  ↓
v2.0  Social experiences
  ↓
v3.0  AI-assisted education
  ↓
v4.0+ Platform expansion
```

Each version adds capability without disrupting existing gameplay.

## Version 1.5 — Content Expansion

Focus: expand content without architectural changes.

- Additional avatar species

- More achievements
- Improved statistics visualisations
- Accessibility enhancements

## Version 2.0 — Social Experiences

Focus: family and group play.

- Family profiles and shared championships
- Replay viewer
- Avatar friendships and interactions
- Richer AI personalities

---

## What Math Racers Must Never Become

The following are prohibited at any version:

- Pay-to-win mechanics
- Gambling-style rewards or loot boxes
- Manipulative daily-login penalties
- Intrusive advertising
- Stressful competitive global rankings
- Excessive push notifications
- Any mechanic that punishes children for missing sessions

---

## Core Principles for All Future Features

Every future feature must satisfy all three pillars:

| Pillar | Question |
|--------|----------|
| Learning | Does this improve or support educational outcomes? |
| Creativity | Does this give children agency to create rather than consume? |
| Joy | Does this make the child smile? |

If a proposed feature cannot answer "yes" to all three, it should not be built.

---

## Success Metrics

| Category | Metric |
|----------|--------|
| Educational | Accuracy improvement over time; response speed improvement |
| Engagement | Average session length (target 10–15 min); return frequency |
| Quality | Avatar acceptance rate; generation success rate; crash rate |

Business metrics never compromise educational goals.
